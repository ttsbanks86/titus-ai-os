# Tool Stack

## Tier 1: Use Immediately

### OpenCode Content Database

Role: generate and manage the content inventory.

Output:

- 100 post ideas.
- 100 captions.
- 100 hooks.
- 100 CTA variations.
- 30 scripts for short videos.
- Brand2Social CSVs.
- Canva Bulk Create CSVs.

### Marky

Role: brand and draft engine.

Use for:

- AI Profile tuning.
- Topic ideation.
- Caption examples.
- Draft posts.
- Testing brand voice.

Do not use for:

- Blind publishing.
- Connecting social accounts before pages are ready.

### Brand2Social

Role: scheduling and distribution.

Use for:

- Uploading CSV schedules.
- Posting across connected profiles.
- Managing comments/DM features if official integrations support them.

Rules:

- Use single-value fields in CSVs.
- Avoid slash-combo values like `Post/Reel`.
- Keep YouTube CSV separate if validators conflict.

### Canva Bulk Create

Role: generate 100 branded static or carousel assets from spreadsheet rows.

Use for:

- Tip cards.
- Carousel slides.
- Quote posts.
- Checklist posts.
- Lead magnet promos.

Quality standard:

- Use 3 to 5 templates, not 1 template repeated 100 times.
- Keep visual identity consistent but vary layout.

## Tier 2: Test Before Buying

### InVideo AI

Role: faceless video generation.

Use for:

- Educational AI workflow videos.
- Script-to-video Shorts.
- Simple explainer videos.

Test batch:

- Create 5 videos from our scripts.
- Approve only if they look credible and not generic.

### Hypernatural

Role: stylized AI explainer videos.

Use for:

- Consistent branded character/style.
- More visually unique short videos.

Test batch:

- Create 5 videos with the same series style.
- Compare against InVideo.

### CapCut

Role: final polish.

Use for:

- Captions.
- Hook timing.
- Removing awkward scenes.
- Brand intro/outro.

## Tier 3: Later Options

### Predis.ai

Role: possible all-in-one AI generation and scheduling alternative.

Use only if:

- Brand2Social cannot handle the desired schedule.
- Predis quality is better for our niche.
- Plan limits make sense.

### Quso / OpusClip / Vidyo-style Repurposing

Role: turn long videos into short clips.

Use later when Titus records or creates long-form videos.

## Not First Priority

### NVIDIA Direct Tooling

NVIDIA is infrastructure-level for AI/generative video. It is not the fastest direct path for a 7-day creator operation unless a specific NVIDIA-powered app has a clear workflow. Use creator-facing tools first.

## Final Stack For Week 1

- Content brain: OpenCode.
- Brand/caption drafts: Marky.
- Graphics: Canva Bulk Create.
- Video tests: InVideo AI and Hypernatural.
- Polish: CapCut or Canva.
- Scheduling: Brand2Social.
- Reporting: Live Cowork project files.
