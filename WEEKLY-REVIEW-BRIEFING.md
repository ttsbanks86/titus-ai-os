# Weekly Review Briefing

## Purpose
Reset the system once a week and catch drift early.

## Review
- Work wins
- Work misses
- Home wins
- Home misses
- School filing status
- Downloads/duplicates status
- Cache/storage status
- Follow-ups that stayed open too long

## Questions
- What kept repeating this week?
- What should have been handled sooner?
- What can be deleted or archived?
- What needs a stricter rule next week?

## Output
- Keep
- Fix
- Delete
- File
- Follow up
