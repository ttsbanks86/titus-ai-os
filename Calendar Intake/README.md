# Calendar Intake

Outlook calendar is not currently accessible locally because Outlook is not connected.

Use this folder for calendar exports or quick schedule notes that the Telegram board should consider.

## Supported Inputs
- `.ics` calendar exports
- `.txt` notes with dates and appointments
- `.md` notes with reminders or deadlines

## Example
- `2026-05-24 10:00 AM - Interview prep call`
- `2026-05-26 - School assignment due`
- `2026-05-30 - Follow up with recruiter`

The Telegram board will scan this folder for upcoming dates once calendar items are added.
