# Command Portal — Project Brief

## Purpose
Provide a simple chatbot-style webpage for typing plain English commands or notes without needing to use VS Code like a coder.

## Workflow
1. User opens Command Portal in browser.
2. User types a natural language instruction.
3. Command Portal appends it to `INBOX.md`.
4. OpenCode can later read `INBOX.md`, route the item to the correct project, and act on it.
