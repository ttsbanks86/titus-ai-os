# BA Compass

### A Business Analyst Portfolio Project — BrightCare Home Services (Fictional)

BrightCare Home Services is a **fictional** home-care agency. All data is **synthetic**. This project is a portfolio simulation. You can read more about the project philosophy in [SANDBOX.md](SANDBOX.md).

BA Compass is a full-lifecycle Business Analyst portfolio project. Every phase of the BA workflow is represented: problem definition, stakeholder analysis, requirements documentation, process analysis, KPI design, risk assessment, requirements traceability, and a working web application that brings all requirements to life.

---

## Key Features

- **Business Requirements Document (BRD)** — 16 functional and 8 non-functional requirements with detailed descriptions and acceptance criteria
- **Stakeholder Analysis** — 14 stakeholders mapped across 4 power/interest quadrants with tailored engagement strategies
- **MoSCoW Prioritization** — Structured prioritization exercise that balanced scope, value, and resource constraints
- **Requirements Traceability Matrix** — Bidirectional traceability linking every requirement to test cases and application features
- **KPI Dashboard** — 12 operational KPIs with interactive Recharts visualizations, target comparisons, and trend data
- **Risk Register** — 11 identified risks with probability/impact scoring and mitigation strategies
- **Process Analysis** — As-is and to-be workflow documentation for scheduling, care documentation, and billing processes
- **Interactive Application** — 16 routes, 19 static pages built with Next.js 15 demonstrating all BA requirements in context
- **Test Suite** — 76 unit tests (Jest) and 14 end-to-end tests (Playwright) with TypeScript strict mode
