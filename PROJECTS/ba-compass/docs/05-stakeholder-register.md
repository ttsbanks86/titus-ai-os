## Detailed Stakeholder Profiles

### STK-001: Agency Owner

| Attribute | Detail |
|-----------|--------|
| Role | Agency Owner / Founder |
| Interest | Strategic — business health, growth, reputation, compliance |
| Influence | High — final decision authority, funding approval |
| Needs | Operational visibility, trend data, risk awareness, strategic recommendations |
| Pain Points | No dashboard, anecdotal reporting, cannot identify systemic issues |
| Responsibilities | Strategic direction, funding, final approval |
| Communication | Monthly executive summaries, milestone reviews, KPI reports |
| Decision Authority | Final sign-off on scope, requirements, budget |
| Risks / Concerns | Cost of change, disruption to operations, implementation timeline |

### STK-002: Operations Manager

| Attribute | Detail |
|-----------|--------|
| Role | Operations Manager |
| Interest | Operational — daily service delivery, team coordination |
| Influence | High — operational process ownership |
| Needs | Real-time shift status, gap alerts, escalation visibility, KPI tracking |
| Pain Points | Reactive firefighting, no consolidated view, manual coordination |
| Responsibilities | Daily operations, team management, process improvement |
| Communication | Weekly operational reviews, daily dashboard access, ad-hoc reports |
| Decision Authority | Operational process changes, escalation procedures |
| Risks / Concerns | New system disrupting current workflow, staff training burden |

### STK-003: Scheduling Coordinator

| Attribute | Detail |
|-----------|--------|
| Role | Scheduling Coordinator |
| Interest | Tactical — daily shift creation and caregiver assignment |
| Influence | Medium — firsthand knowledge of scheduling challenges |
| Needs | Gap visibility, shift confirmation tracking, easy status updates |
| Pain Points | Manual calls to fill gaps, no confirmation system, phone tag |
| Responsibilities | Creating schedules, assigning caregivers, filling gaps |
| Communication | Daily operational updates, scheduling reports, shift data entry |
| Decision Authority | Schedule adjustments within operational guidelines |
| Risks / Concerns | Increased data entry burden, technology replacing judgment |

### STK-004: Care Coordinator

| Attribute | Detail |
|-----------|--------|
| Role | Care Coordinator |
| Interest | Tactical — client-caregiver matching, service quality |
| Influence | Medium — client relationship knowledge |
| Needs | Issue escalation path, documentation status, client feedback tracking |
| Pain Points | No structured issue tracking, repeated explanations, no follow-up system |
| Responsibilities | Client assignment, issue resolution, caregiver communication |
| Communication | Daily updates on issues, client feedback, care plan changes |
| Decision Authority | Client reassignment, caregiver changes, service adjustments |
| Risks / Concerns | Inability to customize for unique client needs |

### STK-005: Caregiver

| Attribute | Detail |
|-----------|--------|
| Role | Caregiver (field staff) |
| Interest | Frontline — schedule clarity, issue reporting, documentation |
| Influence | Low — individual limited influence |
| Needs | Clear schedule, easy documentation, issue reporting path |
| Pain Points | Schedule changes without notice, no feedback on reports |
| Responsibilities | Shift completion, service documentation, issue reporting |
| Communication | Schedule notifications, documentation reminders, issue reporting |
| Decision Authority | Shift acceptance / decline within guidelines |
| Risks / Concerns | Technology burden, reduced flexibility, monitoring concerns |

### STK-006: Quality Assurance Lead

| Attribute | Detail |
|-----------|--------|
| Role | Quality Assurance Lead |
| Interest | Compliance — documentation quality, process adherence |
| Influence | Medium — quality standards enforcement |
| Needs | Documentation completion tracking, audit trail, compliance reporting |
| Pain Points | No documentation tracking, cannot identify gaps, audit preparation is manual |
| Responsibilities | Quality monitoring, documentation auditing, compliance reporting |
| Communication | Monthly quality reports, documentation dashboards, audit preparation |
| Decision Authority | Quality standards, documentation requirements |
| Risks / Concerns | Incomplete data, resistance to documentation requirements |

### STK-007: Client Services Representative

| Attribute | Detail |
|-----------|--------|

| Interest | Client-facing — issue intake, client communication |
| Influence | Low — limited process influence |
| Needs | Clear escalation path, issue tracking, client communication templates |

| Responsibilities | Client intake, issue reporting, client communication |
| Communication | Client updates, issue reports, escalation notifications |
| Decision Authority | Issue intake, initial response |
| Risks / Concerns | Technology replacing personal touch, increased monitoring |

### STK-008: IT Administrator

| Attribute | Detail |

| Role | IT Administrator |
| Interest | Technical — system implementation, integration, support |
| Influence | Medium — technical feasibility input |

| Responsibilities | Technical implementation, system support, integration |

| Risks / Concerns | Integration complexity, maintenance burden, security exposure |

| Decision Authority | Compliance requirements, privacy controls |
| Risks / Concerns | Inadequate documentation, privacy breaches, regulatory findings |

### STK-010: Client / Family Representative

|-----------|--------|
