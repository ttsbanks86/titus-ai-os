## Project Purpose

BA Compass is a recruiter-ready Business Analyst portfolio project that demonstrates end-to-end business analysis skills through a fictional home-care services case study. It shows how a Business Analyst identifies operational problems, documents requirements, designs process improvements, defines success metrics, and communicates findings to stakeholders.

---

## Business Problem

BrightCare Home Services, a fictional home-care company, is experiencing systemic operational failures:

- Missed shifts and open staffing gaps reduce service reliability
- Late caregiver arrivals cause client dissatisfaction
- Delayed escalation leaves issues unresolved
- Incomplete service documentation creates compliance and billing risk
- Communication delays force repeated manual follow-up
- Limited operational visibility prevents proactive management
- No consistent KPI dashboard exists to measure performance
- Difficulty identifying recurring service failures

These problems create a cycle of reactive management, client churn risk, and staff burnout. A structured analysis and solution approach is needed.

---

## Project Objectives

1. Document the current-state business process for shift management
2. Identify root causes of operational failures through structured analysis
3. Define business, functional, and nonfunctional requirements for a solution
4. Create traceable user stories with acceptance criteria
5. Define KPIs and success measures for operational improvement
6. Design a future-state process that addresses identified gaps
7. Produce a professional BRD and supporting documentation suite
8. Build a recruiter-facing demonstration tool showcasing BA skills
9. Demonstrate requirements traceability from problem through KPI
10. Produce executive-ready communication deliverables

## Assumptions

1. All data used in this project is synthetic and fictional
2. Recruiters reviewing this project will have limited time (under 10 minutes)
3. Demo users will not create accounts or provide personal information
4. The demonstration tool must work without requiring a paid AI API
5. The project represents a portfolio demonstration, not a production system
6. No real employer, client, or patient data will be used at any stage
7. The solution will be simple enough to host at low or zero cost
8. Mobile and desktop accessibility are required for recruiter review

---

## Constraints

1. No real healthcare, personal, or employer data may be used
2. The project must not depend on a paid third-party API for core functionality
3. Limited development time — this is a solo portfolio project
4. No production deployment for a real home-care agency
5. The project must follow existing workspace repository conventions
6. No modification to production Titus Platform services
7. Low or zero hosting cost for public access
8. Simple technology stack for maintainability
