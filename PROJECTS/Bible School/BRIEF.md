# Bible School — Project Brief

## Purpose
Keep Bible school books, quizzes, notes, assignments, sources, and answer verification separate from other OpenCode work.

## How to Use
When the user says **"open Bible School"**, load this folder as the active context.

## Structure
```text
Bible School
├── BRIEF.md
├── STATUS.md
├── NEXT-ACTIONS.md
├── TEMPLATES
│   └── BOOK-TEMPLATE.md
└── BOOKS
    └── [Each book gets its own folder]
```

## Book Folder Standard
Each book should use:

```text
[Book Title]
├── BOOK-BRIEF.md
├── NOTES
├── QUIZZES
├── SOURCES
└── ASSIGNMENTS
```

## Current Active Book
- *Rethinking the Church* by James Emery White

## Workflow
1. Receive quiz questions, assignment instructions, or reading notes.
2. Identify the active book.
3. Search/verify answers from the book source when possible.
4. Present answers clearly.
5. Save completed work in the correct book folder.
