## Day 1: Review Link Setup

☐ **QR Code Created**
- Generate QR code linking to Google review page
- Test QR code on mobile device
- Save QR code as PNG file

☐ **Short URL Created**
- Create short URL (e.g., bit.ly/{{Business}}-reviews)
- Test short URL on mobile device
- Save short URL in client folder

☐ **Review Page Verified**
- Confirm Google Business Profile review page is active
- Confirm review page loads correctly on mobile
- Confirm review page loads correctly on desktop

---

## Day 1-2: Review Request Templates

☐ **Email Template Created**
- Customize email template with business name and branding
- Include review link in email
- Include unsubscribe link (CAN-SPAM compliance)
- Test email on desktop and mobile

☐ **Text Message Template Created**
- Customize text message template with business name
- Include review link in text
- Include opt-out option
- Test text on mobile

☐ **5-Touch Sequence Configured**
- Touch 1: Initial review request (Day 1 after service)
- Touch 2: Reminder (Day 3)
- Touch 3: Final reminder (Day 7)
- Touch 4: Thank you (after review submitted)
- Touch 5: Referral request (Day 30)

---

## Day 2: Private Feedback Form

☐ **Google Form Created**
- Create Google Form with business branding
- Include fields: Name, Email, Phone, Service Date, Rating (1-5), Comments
- Set up email notifications for new submissions
- Test form submission

☐ **Feedback Form Linked**
- Add feedback form link to email templates
- Add feedback form link to website
- Add feedback form link to email signature
- Test all links

---

## Day 2-3: Review Response Templates

☐ **Positive Review Response Template**
- Create template for 4-5 star reviews
- Include personalized elements (customer name, service type)
- Test template with sample review

☐ **Negative Review Response Template**
- Create template for 1-3 star reviews
- Include empathy, apology, and resolution offer
- Include invitation to discuss offline
- Test template with sample review

☐ **Neutral Review Response Template**
- Create template for 3-4 star reviews
- Include gratitude and improvement commitment
- Include invitation to discuss
- Test template with sample review

---

## Day 3: Final Setup

☐ **Review Monitoring Setup**
- Set up daily review monitoring (Google Business Profile)
- Set up alerts for new reviews
- Confirm monitoring is working

☐ **Client Access Confirmed**
- Client can access Google Business Profile
- Client can access review request templates
- Client can access feedback form
- Client can access response templates

☐ **Client Training Completed**
- Walk client through review request process
- Walk client through feedback form process
- Walk client through review response process
- Answer client questions

☐ **Documentation Delivered**
- Send client setup summary document
- Include all links and templates
- Include contact information for support
- Include next steps

---

## Post-Setup

☐ **First Review Request Sent**
- Send first review request to recent customers
- Track opens and replies
- Follow up as needed

☐ **First Review Responded To**
- Respond to first new review using templates
- Confirm response is professional and on-brand

☐ **First Monthly Report Prepared**
- Prepare first monthly review growth report
- Include: review count, response rate, sentiment analysis
- Send report to client
