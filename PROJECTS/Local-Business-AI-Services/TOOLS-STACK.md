## Recommended Setup Order

**Day 1 (30 minutes):**
1. Create a new Gmail account for the business (or use existing)
2. Set up Google Sheets CRM (copy the template from `_data/LEAD-TRACKER.csv`)
3. Set up Calendly (free tier, 1 event type: "15-Minute Business Review")
4. Set up MailerLite (free account, create first form)

**Day 2 (15 minutes):**
1. Set up Stripe (link to bank account)
2. Create a simple invoice template in Google Sheets
3. Test Calendly booking link

**Day 3 (10 minutes):**
1. Record a 60-second Loom intro video
2. Create a simple landing page on Cloudflare Pages (optional)
3. Set up Google Voice business number (optional)

## Critical Rule

**Do not buy any tool before proving demand.** The first 3 clients should be closed with free tools only. If the business model works, then invest in paid tools to scale.

**Monthly cost at 0 clients:** $0
**Monthly cost at 5 clients:** $0-50 (Stripe fees only)
**Monthly cost at 10 clients:** $50-100 (maybe MailerLite paid tier)
**Monthly cost at 20 clients:** $100-200 (Airtable + MailerLite + maybe Twilio)
