## Usage Notes
- Always include data sources and date ranges
- Use consistent color coding: 🟢 On Track, 🟡 At Risk, 🔴 Off Track
- Include year-over-year or period-over-period comparisons
- Add executive summary at the top for quick scanning
- Link to detailed data sources when available
