# Email Templates Library

## Cold Outreach

### Template 1: Initial Cold Outreach
```
Subject: [FIRST_NAME] — Quick question about [COMPANY]'s [PAIN_POINT]

Hi [FIRST_NAME],

I noticed [COMPANY] has been [OBSERVATION — e.g., "expanding into new markets" or "hiring aggressively"]. Companies at this stage often struggle with [PAIN_POINT].

We helped [SIMILAR_COMPANY] achieve [RESULT] in [TIMEFRAME]. I think we could do something similar for [COMPANY].

Would you be open to a 15-minute call next week to explore this?

Best,
[YOUR_NAME]
```

### Template 2: LinkedIn Connection + Follow-Up
```
Subject: Thanks for connecting, [FIRST_NAME]

Hi [FIRST_NAME],

Thanks for connecting! I've been following [COMPANY]'s work in [INDUSTRY] — impressive what you've built.

I work with [TARGET_COMPANY_TYPE] on [VALUE_PROPOSITION]. Would love to learn more about what you're working on.

Any interest in a quick chat?

Best,
[YOUR_NAME]
```

## Follow-Up Sequences

### Template 3: Follow-Up #1 (3 Days)
```
Subject: Re: [ORIGINAL_SUBJECT]

Hi [FIRST_NAME],

Just bumping this up in your inbox. I know things get busy.

Quick recap: I reached out about [VALUE_PROPOSITION] for [COMPANY]. I think there's a strong fit here.

Would a 15-minute call work this week?

Best,
[YOUR_NAME]
```

### Template 4: Follow-Up #2 (7 Days)
```
Subject: Re: [ORIGINAL_SUBJECT]

Hi [FIRST_NAME],

I wanted to share something that might be relevant — [RELEVANT_CONTENT_LINK or INSIGHT].

This is similar to what we did for [SIMILAR_COMPANY] when they faced [CHALLENGE].

Happy to walk through how this might apply to [COMPANY] if you're interested.

Best,
[YOUR_NAME]
```

### Template 5: Final Follow-Up (14 Days)
```
Subject: Re: [ORIGINAL_SUBJECT]

Hi [FIRST_NAME],

I'll keep this brief — I know your time is valuable.

If [VALUE_PROPOSITION] isn't a priority right now, no worries at all. But if it is, I'd love to chat.

If not, would you mind pointing me to the right person on your team to discuss?

Best,
[YOUR_NAME]
```

## Client Communication

### Template 6: Project Update
```
Subject: [PROJECT_NAME] — Weekly Update ([DATE])

Hi [CLIENT_NAME],

Here's this week's progress on [PROJECT_NAME]:

COMPLETED:
- [TASK_1]
- [TASK_2]

IN PROGRESS:
- [TASK_3] — on track for [DATE]
- [TASK_4] — needs your input on [ITEM]

BLOCKERS:
- [BLOCKER] — need [RESOURCE/DECISION] to proceed

NEXT WEEK:
- [PLANNED_TASK_1]
- [PLANNED_TASK_2]

Let me know if you have any questions.

Best,
[YOUR_NAME]
```

### Template 7: Proposal Follow-Up
```
Subject: Re: [PROPOSAL_NAME] — Any questions?

Hi [CLIENT_NAME],

Following up on the proposal I sent on [DATE]. I know you're reviewing several options, so I wanted to make sure you have everything you need.

Key highlights:
- [KEY_BENEFIT_1]
- [KEY_BENEFIT_2]
- [KEY_BENEFIT_3]

Happy to jump on a call to walk through any questions.

Best,
[YOUR_NAME]
```

## Internal Communication

### Template 8: Meeting Request
```
Subject: Meeting Request: [TOPIC]

Hi [ATTENDEE_NAME],

I'd like to schedule a meeting to discuss [TOPIC]. Here are the details:

Agenda:
1. [ITEM_1]
2. [ITEM_2]
3. [ITEM_3]

Duration: [LENGTH]
Proposed times:
- [OPTION_1]
- [OPTION_2]
- [OPTION_3]

Let me know what works best.

Best,
[YOUR_NAME]
```

### Template 9: Status Update Request
```
Subject: Status Request: [PROJECT/TASK_NAME]

Hi [NAME],

Could you provide a quick status update on [PROJECT/TASK]?

I need to know:
1. Current progress
2. Any blockers
3. Expected completion date
4. Resources needed

Please reply by [DATE/TIME].

Thanks,
[YOUR_NAME]
```

## Usage Notes
- Always personalize templates with specific details
- Test subject lines for open rate optimization
- Track which templates perform best
- Update templates quarterly based on results
- Keep tone consistent with brand voice (see `brand-guidelines` skill)
