# Daily Workflow

## Overview
Recurring daily operations workflow for the Live Cowork ecosystem. Execute in order each business day.

- **End Time:** [END_TIME]

---

## Morning Block (First 2 Hours)

### 1. System Check (15 min)
```
1. Check email inbox for urgent items
2. Review calendar for today's meetings
3. Check task management system for overdue items
4. Review overnight notifications/messages
```

### 2. Email Triage (30 min)
```
1. Process all new emails per Email Triage SOP
2. Apply labels and categories
3. Draft responses for urgent items
4. Flag follow-ups needed
```
**SOP Reference:** `SOPs/email-triage-sop.md`

### 3. Lead Review (30 min)
```
1. Check new leads from all sources
2. Score and qualify new leads
3. Update CRM/pipeline status
4. Schedule outreach for hot leads
```
**SOP Reference:** `SOPs/lead-management-sop.md`

### 4. Team Standup (15 min)
```
1. Share yesterday's accomplishments
2. State today's top 3 priorities
3. Identify any blockers
4. Coordinate with team members
```

---

## Core Work Block (4-5 Hours)

### 5. Priority Task Execution (2-3 hours)
```
1. Work on highest priority task from morning review
2. Focus on single task (no multitasking)
3. Log progress in task management system
4. Flag any blockers immediately
```

### 6. Communication Block (1 hour)
```
1. Respond to all pending emails
2. Follow up on outstanding requests
3. Update stakeholders on progress
4. Process internal messages
```

### 7. Client Work (1-2 hours)
```
1. Execute client deliverables
2. Update client on project status
3. Handle client requests
4. Document any scope changes
```

---

## Afternoon Block (2-3 Hours)

### 8. Research & Development (1 hour)
```
1. Research market/competitors
2. Identify new opportunities
3. Review industry news
4. Update knowledge base
```

### 9. Admin Tasks (30 min)
```
1. Update CRM records
2. File documents
3. Process invoices
4. Update tracking spreadsheets
```

### 10. End-of-Day Review (30 min)
```
1. Review today's accomplishments
2. Update task statuses
3. Prepare tomorrow's priority list
4. Set any needed reminders
```
