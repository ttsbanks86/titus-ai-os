# Weekly Workflow

## Overview
Weekly review and planning workflow. Execute every [DAY] to close out the current week and prepare for the next.

## Schedule
- **Day:** Every [DAY]
- **Duration:** 2-3 hours
- **Owner:** [NAME/ROLE]

---

## Part 1: Week Review (1 Hour)

### 1. Metrics Review (20 min)
```
1. Pull weekly metrics from all sources:
   - Leads generated vs. target
   - Conversions vs. target
   - Revenue vs. forecast
   - Task completion rate
   - Client satisfaction scores
2. Calculate week-over-week trends
3. Identify top-performing areas
4. Flag underperforming areas
```
**Template:** `Templates/report-templates.md` (Weekly Summary)

### 2. Goal Progress Check (20 min)
```
1. Review monthly/quarterly goals
2. Calculate progress percentage
3. Determine if on track (🟢🟡🔴)
4. Adjust next week's focus if needed
```

### 3. Wins & Challenges (20 min)
```
1. Document top 3 wins of the week
2. Document top 3 challenges
3. Analyze root causes
4. Identify solutions for challenges
```

---

## Part 2: Pipeline Review (30 min)

### 4. Lead Pipeline (15 min)
```
1. Review all leads by stage
2. Identify stuck leads (no movement >7 days)
3. Plan outreach for stalled leads
4. Update lead scores based on activity
```

### 5. Client Pipeline (15 min)
```
1. Review all active client projects
2. Check milestone status
3. Identify at-risk projects
4. Plan client communication
```

---

## Part 3: Next Week Planning (1 Hour)

### 6. Priority Setting (20 min)
```
1. Define top 3 priorities for next week
2. Break priorities into daily tasks
3. Assign owners and deadlines
4. Block calendar time for deep work
```

### 7. Meeting Prep (20 min)
```
1. Review all meetings scheduled for next week
2. Prepare agendas for meetings you lead
3. Gather materials needed
4. Send advance prep to attendees
```

### 8. Communication Planning (20 min)
```
1. Plan email sequences for next week
2. Schedule social media content
3. Prepare client updates
4. Draft any needed proposals
```

---

## Part 4: Team Coordination (30 min)

### 9. Team Review Meeting
```
Agenda:
1. Week review highlights (10 min)
2. Individual updates (15 min)
3. Next week priorities (10 min)
4. Blockers and support needs (5 min)
```
