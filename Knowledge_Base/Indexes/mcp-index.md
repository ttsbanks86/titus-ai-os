# MCP Index

## Overview
Complete index of all Model Context Protocol (MCP) servers available in the Live Cowork ecosystem.

---

## Communication MCPs

### Gmail MCP
- **Purpose:** Email management and automation
- **Key Functions:** Read, send, search, label, filter emails
- **Access:** Via gmail-automation skill
- **Location:** `~/.config/opencode/skills/gmail-automation/`
- **Tags:** email, communication, automation

### LinkedIn MCP
- **Purpose:** Professional networking and lead research
- **Key Functions:** Search people, send messages, view profiles, company research
- **Access:** LinkedIn tools in OpenCode
- **Location:** Built-in LinkedIn integration
- **Tags:** networking, leads, research, social
