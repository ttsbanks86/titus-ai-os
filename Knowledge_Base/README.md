# Knowledge Base

## Purpose
Central repository for all operational knowledge, procedures, templates, and agent instructions for the Live Cowork ecosystem. Designed for both human and AI agent consumption.

## Structure Overview
```
Knowledge_Base/
├── README.md              # This file — overview and navigation
├── SOPs/                  # Standard Operating Procedures
├── Templates/             # Reusable templates and frameworks
├── Workflows/             # Daily, weekly, monthly workflows
├── Agent-Instructions/    # AI agent operating guides
└── Indexes/               # Quick reference indexes
```

## How to Use This Knowledge Base

### For Humans
1. Start with the **Indexes/** folder for quick lookups
2. Follow **SOPs/** for step-by-step procedures
3. Use **Templates/** for repeatable outputs
4. Reference **Workflows/** for scheduling and cadence
5. Check **Agent-Instructions/** for AI delegation

### For AI Agents
1. Load the relevant **Agent-Instructions/** guide for your role
2. Follow the SOPs matching your current task
3. Use templates from **Templates/** for output formatting
4. Execute workflows from **Workflows/** for timing and steps
5. Cross-reference **Indexes/** for tool/command lookups

## Maintenance Procedures

### Weekly
- Review and update any outdated SOPs
- Verify template placeholders are current
- Check agent guides for new tool integrations

### Monthly
- Audit all indexes for completeness
- Archive deprecated procedures
- Update version histories across all files
- Review escalation paths with team

### Versioning Convention
- All files use `v[Major].[Minor].[Patch]` format
- Major = structural overhaul
- Minor = content addition or update
- Patch = typo fixes or clarifications

## Contributing
- Use `Templates/sop-template.md` for new SOPs
- Use `Templates/report-templates.md` for reports
- Update the relevant index after adding any file
- Notify team lead after major changes
