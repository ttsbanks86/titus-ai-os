# Meeting Recap SOP

## 1. Purpose
Ensure all meetings are documented with clear action items, decisions, and follow-ups to maintain accountability and institutional knowledge.

## 2. Scope
All business meetings: internal team calls, client meetings, vendor calls, strategy sessions, and one-on-ones.

## 3. Prerequisites
- Meeting transcript capability (Zoom/Teams recording)
- Notion access for documentation
- Calendar access for scheduling follow-ups
- Action item tracking system

## 4. Procedure

### Step 1: Pre-Meeting Preparation
```
1. Review agenda (if provided)
2. Pull relevant context from previous meeting notes
3. Prepare attendee list
4. Note any open items to discuss
```

### Step 2: During Meeting
```
1. Take notes using structured format:
   - DECISIONS: [What was decided]
   - ACTION ITEMS: [Who does what by when]
   - DISCUSSION: [Key points discussed]
   - OPEN ITEMS: [Unresolved topics]
2. Clarify action items verbally:
   "So [Name] will [Task] by [Date] — is that correct?"
```

### Step 3: Post-Meeting Recap (Within 2 Hours)
```
1. Compile notes into structured format
2. Create recap document in Notion with:
   - Meeting title and date
   - Attendees
   - Agenda items covered
   - Decisions made
   - Action items (with owners and due dates)
   - Next meeting date/time
3. Share recap with all attendees
```

### Step 4: Action Item Tracking
```
1. Add all action items to task management system
2. Set reminders for due dates
3. Schedule check-in for unresolved items
4. Link recap document to action items
```

### Step 5: Follow-Up
```
1. Before next meeting, review previous action items
2. Update status of each item
3. Prepare agenda item for status updates
4. Escalate any overdue items
```

## 5. Quality Checks
- [ ] Recap sent within 2 hours of meeting
- [ ] All action items have owners and due dates
- [ ] Decisions clearly documented
- [ ] Next meeting scheduled
- [ ] Action items entered into tracking system

## 6. Escalation Path
| Issue | Escalate To | Method |
|-------|------------|--------|
| Action item overdue | Item owner + Manager | Email reminder |
| Recurring unresolved item | Meeting organizer | Agenda flagging |
| Missing meeting notes | Meeting organizer | Direct request |
| Conflict in decisions | Team Lead | Ad-hoc meeting |
