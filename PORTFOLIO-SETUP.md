# Portfolio Setup Guide

## Best Setup
Use **Notion** as the main portfolio hub.

Why:
- Fast to build
- Easy to update
- Clean links from LinkedIn
- Good for project pages, screenshots, notes, and files

## Optional Add-Ons
- **Google Drive** for source files
- **GitHub** only for clean analyst or automation artifacts
- **Power BI public link** or screenshots for dashboards
- **Jira / Confluence screenshots** for process and requirements work

## Recommended Portfolio Structure
- Home
- About Me
- Resume
- Projects
- Skills
- Contact

## Projects To Build First
1. **Client Intake Workflow Improvement**
- current process
- pain points
- improved process
- requirements
- stakeholder list
- KPI ideas

2. **Operations Dashboard**
- one KPI dashboard in Power BI or Excel
- simple summary of what it shows
- business value

3. **Requirements and User Stories Pack**
- problem statement
- user stories
- acceptance criteria
- backlog priorities

## What To Put On LinkedIn
- Link to the Notion portfolio home page
- 3 featured project pages
- one dashboard link or screenshot gallery

## What To Avoid
- IT support labs as the main feature
- cluttered folders
- too many unfinished projects
- anything that makes you look like only help desk

## Simple Rule
If it helps you explain how you analyze, improve, document, or coordinate work, it belongs in the portfolio.
