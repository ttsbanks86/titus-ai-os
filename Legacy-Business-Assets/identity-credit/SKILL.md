# Identity-and-Credit Workstream

## Overview
Integrated workflow combining credit repair with identity protection (data broker removal).

## 7-Phase Workflow

### Phase 0: Disposable Contact Kit
- Create dedicated email (protonmail or tutanota)
- Get virtual phone number (Google Voice or Hushed)
- Set up password manager (Bitwarden)

### Phase 1: Pull + Audit Credit Reports
- Pull from AnnualCreditReport.com (all 3 bureaus)
- Review for errors, unknown accounts, suspicious activity
- Document everything in credit-audit-tracker.md

### Phase 2: Credit Disputes
- Dispute errors with all 3 bureaus
- Use certified mail (USPS with tracking)
- Track in credit-audit-tracker.md
- Templates: dispute-letter.md, dispute-escalation-letter.md

### Phase 3: ID Eraser Phase 1 - People Search
- Submit opt-outs to major people search sites
- Spokeo, Whitepages, BeenVerified, Intelius, PeopleFinder
- Track in id-eraser-tracker.md
- Templates: data-broker-opt-out-letter.md

### Phase 4: ID Eraser Phase 2 - Background Checks
- Opt out of background check sites
- Checkr, GoodHire, Sterling, First Advantage
- Track in id-eraser-tracker.md

### Phase 5: Credit Repair Negotiation
- Goodwill letters to creditors
- Pay-for-delete negotiations
- Credit limit increase requests
- Templates: goodwill-letter.md, pay-for-delete-letter.md

### Phase 6: ID Eraser Phase 3 - Phone/Address/Search/Social
- Remove from phone lookup sites
- Remove from address lookup sites
- Opt out of Google search results
- Clean up social media profiles

### Phase 7: Credit Building + Monitoring
- Secured credit card
- Credit-builder loan
- Authorized user strategy
- Credit monitoring setup

## Fraud Sub-Protocol
If fraud detected:
1. File police report
2. File FTC report at IdentityTheft.gov
3. Place fraud alert with all 3 bureaus
4. Freeze credit with all 3 bureaus
5. Dispute fraudulent accounts as fraud
6. Contact creditors directly
7. Set up credit monitoring
