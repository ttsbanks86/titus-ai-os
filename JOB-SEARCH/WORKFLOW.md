# Titus Banks Job Search Workflow
**Owner:** Titus Banks
**Created:** 2026-06-06
**Philosophy:** Quality over quantity. Tailored applications. Faith-rooted integrity.

---

## Core Principle

We do not mass apply. We do not lazy apply. We do not spam recruiters. Every application is a thoughtful, tailored submission that treats the employer with the same respect we want shown to us.

---

## The 8-Stage Flow

### Stage 1: Source Resume
- **Three master resumes live in `Resume/`:**
  - `Titus_Banks_MASTER_PM_Private.docx` - private/public/non-profit PM roles (default)
  - `Titus_Banks_MASTER_PM_Federal.docx` - federal government and government contractor PM roles
  - `Titus_Banks_MASTER_BA.docx` - Business Analyst roles (DRAFT pending user review)
- **Source of truth bio:** `Resume/TITUS_BANKS_MASTER_BIO.md`
- See `Resume/RESUME_MANAGEMENT.md` for full rules (two-resume rule, edit workflow, Claude project mapping)
- These are the source of truth for all tailoring
- Update these files whenever experience, skills, or certifications change

### Stage 2: Preference Profile
- Job search preferences live in `PREFERENCES.md`
- Target role, salary floor, work type, industries, location radius, start date
- Update this when priorities shift

### Stage 3: Job Discovery (AI-led)
- AI scrapes LinkedIn, Indeed, ZipRecruiter, Glassdoor via Apify MCP
- Filters by: title, location, salary floor, work type, experience level, posting date
- Output: a curated list of 20-50 potential matches per search

### Stage 4: Match Scoring (AI-led)
- For each job, AI generates a fit score 1-100
- Scoring based on: required skills vs resume, experience level match, salary alignment, industry fit, location preference
- Output: ranked list, top 10-15 selected for active pursuit

### Stage 5: Job Selection (Joint)
- Human reviews the ranked list
- Human picks the jobs to actually apply to
- No more than 5-10 active applications in flight at a time to keep quality high

### Stage 6: Tailored Package (AI + Claude, with human review)
- For each selected job, OpenCode creates a folder inside `Current Job Application/`
- Folder name format: `YYYY-MM-DD_CompanyName_RoleName` (no spaces in folder name)
- **Two-AI workflow per application:**
  1. OpenCode generates the initial draft: `Resume_Tailored.md` + `Cover_Letter.md` (using master + JD)
  2. User opens Claude (browser) at claude.ai -> Project: "Job Search: Project Management"
     - Pastes JD + draft + asks Claude to refine narrative, tighten bullets, surface keywords
     - Claude returns refined Markdown
  3. User pastes refined Markdown back into the job folder (overwrites draft)
  4. OpenCode converts refined .md to .docx (and PDF) for final submission
- Each folder contains:
  - `Resume_Tailored.md` (Markdown source, edited in Claude)
  - `Resume_Tailored.docx` (DOCX for ATS, generated by OpenCode)
  - `Resume_Tailored.pdf` (PDF for final upload, generated by OpenCode)
  - `Cover_Letter.md` (Markdown source)
  - `Cover_Letter.docx` + `.pdf` (final)
  - `JD.md` (job description snapshot)
  - `Match_Scorecard.md` (fit analysis)
  - `Company_Research.md`
  - `Application_Notes.md` (status, contacts, follow-ups)
- **Two-resume rule:** Federal roles use PM Federal master. All other roles use PM Private or BA master. See `RESUME_MANAGEMENT.md`.

### Stage 7: Application Submission (Joint)
- Human creates the account on the company career site or job board
- AI helps fill out forms as quickly as possible (browser automation via Playwright MCP)
- AI drafts answers to common application questions (work auth, salary history, EEO, etc.)
- Human reviews all answers before submission
- Human clicks final submit
- Human uploads tailored resume, cover letter, and any required documents

### Stage 8: Post-Application (Joint)
- Move folder from `Current Job Application/` to `Archive/YYYY-MM/`
- Update `Tracker/APPLICATIONS.csv` with status, date, contact info
- Set follow-up reminder (7-14 days after submission)
- AI drafts follow-up email if no response after 14 days
- Track status changes: Applied > Screening > Interview > Offer > Accepted/Rejected
- Weekly review of all in-flight applications

## Status Values (Tracker)

| Status | Meaning |
|---|---|
| `Sourced` | Identified but not selected |
| `Selected` | Picked for active pursuit, prep in progress |
| `Ready` | Tailored package complete, waiting for submission |
| `Applying` | Form fill in progress |
| `Submitted` | Application sent |
| `Screening` | Recruiter or HR screen scheduled or in progress |
| `Interview-1` | First interview scheduled or completed |
| `Interview-2` | Second round |
| `Interview-3` | Third round or panel |
| `Offer` | Offer received |
| `Accepted` | Offer accepted |
| `Rejected` | Application rejected |
| `Withdrawn` | We withdrew the application |
| `Ghosted` | No response after 21+ days |

## What AI Does

- Discovers jobs (scrapes, filters, ranks)
- Scores fit (1-100 against resume)
- Tailors resume and cover letter per job
- Drafts all written content
- Fills out application forms via browser automation
- Tracks all applications
- Drafts follow-up emails
- Sends weekly digests
- Researches companies and interviewers
- Preps interview answers

## What Human Does

- Sets preferences and priorities
- Selects which jobs to actually apply to
- Reviews all AI-generated content before submission
- Creates accounts on job sites
- Clicks final submit
- Uploads final documents
- Attends interviews
- Makes all final decisions (apply or not, accept or not)

---

## Quality Rules

- Never submit an application without human review
- Never use the same cover letter twice
- Never claim skills or experience the resume does not back up
- Never lie about salary history or expectations
- Always follow up within 14 days if no response
- Always send a thank-you after every interview
- Always withdraw applications when accepting another offer (leave bridges intact)
- Always honor non-compete and non-solicitation terms

---

## Cost Guardrails

- Apify: max $5/month (free tier covers ~50-100 job scrapes)
- LinkedIn scraper: 1-2 scrapes per week (avoid rate limits)
- Job board: max 5-10 active applications at a time
- Daily time budget: 1-2 hours max for application work

## Cadence

| Frequency | Activity |

| Daily | Apply to 1-2 selected jobs, update statuses |
| Per application | Update tracker, set follow-up reminder |
