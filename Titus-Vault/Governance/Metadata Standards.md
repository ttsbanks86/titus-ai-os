# Metadata Standards

Every active note uses these properties when values are verifiable:

```yaml
owner:
domain:
status:
priority:
project:
area:
created:
updated:
reviewed:
related:
tags:
```

Use ISO dates (`YYYY-MM-DD`). Use wikilinks in `related`. Do not populate unknown values. Uncertain ownership or classification requires `status: Review Required` and placement in the appropriate Review queue.

Allowed project statuses are defined in [[Project Rules]].
