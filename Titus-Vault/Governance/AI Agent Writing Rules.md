# AI Agent Writing Rules

Before creating a note, search the vault. If an authoritative note exists, update it without erasing history. Create a new note only when the subject is distinct.

Agents must:

- use verifiable metadata only;
- preserve quotations and provenance;
- connect active notes to a hub;
- send uncertainty to Review;
- avoid permanent deletion;
- process at most 100 migrated notes per batch;
- validate links, backlinks, embeds, Dataview, and graph relationships after each batch;
- append outcomes to [[Migration History]].
