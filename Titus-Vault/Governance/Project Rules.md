# Project Rules

Every project has exactly one status:

- **Prioritizing:** current focus.
- **Active:** worked regularly.
- **Planned:** approved but waiting.
- **Inactive:** not currently pursued.
- **Completed:** verified finished.
- **Archived:** historical.
- **Utility:** personal support tool.
- **Review Required:** needs human review.

Status changes belong in [[Decision Log]]. Completed and Archived require evidence; never infer completion from age or inactivity.
