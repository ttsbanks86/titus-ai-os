# Floating AI Tutor

## Overview
A desktop overlay AI tutor that provides contextual learning assistance. The tutor appears as a floating overlay, providing explanations, answering questions, and guiding learning without interrupting workflow.

## Current State
- Phase: Concept
- Last updated: 2026-06-21
- Status: Early ideation

## Goals
- Create a non-intrusive learning assistant
- Provide contextual help based on what the user is working on
- Support multiple subjects and skill levels
