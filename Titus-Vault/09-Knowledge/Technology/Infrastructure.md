# Infrastructure

## Overview
Hosting, servers, deployment details for the Titus AI OS.

## Current Infrastructure
- All systems run locally on Windows 11 desktop
- No cloud hosting currently active
- Hermes runs via OpenRouter (cloud API router)
- Potential future: Vercel, Railway for web apps

## Local Setup
- OS: Windows 11
- Shell: PowerShell 5.1
- Python: Available for scripting
- Node.js: Available for web development
- Ollama: Local model serving (qwen2.5-coder:14b, gemma2:2b)
