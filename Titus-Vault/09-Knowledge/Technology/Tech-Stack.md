# Tech Stack

## Overview
Current technology choices for the Titus AI OS and associated products.

## Core Stack
- Runtime: OpenCode (canonical)
- Models: Local (qwen2.5-coder, gemma2), Cloud (Anthropic, OpenAI, OpenCodeGo — when loaded)
- Media Generation: KIE API (nano-banana-2 for images, omnihuman-1-5 for avatar video)
- Browser: Playwright (via MCP)
- Search: Firecrawl, Perplexity (via MCP)
- Knowledge: Obsidian vault (file-based, plain markdown)
- Memory: Direct file I/O to vault (not claude-mem — connection down)
- Design: YUV.AI design system (Neon mode, Decks mode)

## Platforms
- Desktop: Windows 11
- Development: VS Code, PowerShell, Python
- Web: Next.js, React, HTML/CSS/JS
- Collaboration: GitHub, Notion
