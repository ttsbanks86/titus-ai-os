# Tools Reference

## Overview
Tools, subscriptions, and licenses used in the Titus AI OS.

## Active Tools
- OpenCode: AI coding assistant (primary runtime)
- VS Code: Code editor
- Obsidian: Knowledge management
- PowerShell: System automation
- Git/GitHub: Version control
- Ollama: Local model inference
- KIE API: Media generation

## Subscriptions
- KIE API: Pay-per-use media generation (~$0.04-0.06 per image)
- OpenRouter: Pay-per-use model routing (Hermes)
- LinkedIn Premium: Job search (if active)
