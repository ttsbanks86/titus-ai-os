# Rollback Instructions

Batch 006 created TKOS metadata and reports only. It did not modify source evidence.

To roll back the TKOS layer:

1. Preserve the source evidence and Phase 2 discovery reports.
2. Revert the Batch 006 Git commit identified in [[Migration History]].
3. Confirm that `Titus/Evidence`, the new education hubs, and Batch 006 reports return to their pre-batch state.
4. Run Obsidian link and runtime validation.

Do not delete or alter Gmail, Drive, OneDrive, iCloud, or local originals during rollback.
