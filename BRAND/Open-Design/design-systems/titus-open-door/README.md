# Titus Open Door Open Design Package

This folder contains the reusable Open Design design-system package for Titus Banks and The Open Door AI Systems.

## Files

- `DESIGN.md`: Full design system and agent prompt guide.
- `open-design.json`: Open Design plugin manifest matching the bundled design-system plugin pattern.

## Intended use

Use this system for:

- Open Door AI Systems pages and product mockups.
- Titus executive dashboards and JARVIS-style command centers.
- Divine Works Hub and faith-rooted assets when no narrower sub-brand file exists.
- Faithful Journey Quest assets with additional ministry-specific direction.
- Struck Down But Not Destroyed marketing assets with book-specific overrides.

## Operating rules

- Local-first by default.
- No secrets are stored in this folder.
- Keep Open Design connected to OpenCode for cost-first generation.
- Do not use cloud providers or paid credits without explicit approval.
- Preserve this folder as the source of truth. Do not edit bundled Open Design files directly unless approved.
