# Daily Briefing System

## Goal
Keep Titus on track like a busy, already-organized person. No Gmail dependency.

## Sources
- Job tracker
- LinkedIn / recruiter alerts
- Downloads organizer log
- School file structure
- Personal critical docs
- Disk and cache status
- Home task list
- Weather

## Morning Briefing
Use this at the start of the day.

### 1. Today At A Glance
- Weather
- System health
- Disk space
- New alerts

### 2. Main Priorities
- Work priority
- Home priority
- Admin priority

### 3. Follow-Up Radar
- Anything pending from yesterday
- Anything waiting on someone else
- Anything that was started but not finished

### 4. Behind List
- Job applications not sent
- Recruiters not answered
- Files not filed
- Home tasks not done
- School items not sorted

### 5. One Assignment
- One thing to finish before noon

## Midday Briefing
Use this to reset the day.

### 1. Progress Check
- What got done
- What slipped
- What is blocked

### 2. Next Moves
- Next work task
- Next home task
- Next file cleanup task

### 3. Catch-Up
- Overdue follow-ups
- Messages to send
- Downloads still waiting

## Evening Briefing
Use this to close the day.

### 1. Wins
- Completed work
- Completed home items
- Completed cleanup

### 2. Misses
- What was not finished
- What needs to move to tomorrow

### 3. Tomorrow Prep
- Top 3 tasks for tomorrow
- One thing to remove
- One thing to file

## Follow-Up Radar Rules
- If something is mentioned twice and not done, mark it overdue.
- If something sits more than 24 hours, it becomes a priority.
- If a task is vague, turn it into a single next action.
- If Gmail fails, keep briefing with everything else.

## Output Format
When I brief you, I should say:
- What matters now
- What you are behind on
- What to do next
- What can wait
- What to delete, file, or archive

## Success Standard
This briefing should feel like an organized person checking their day, not a random notification dump.
