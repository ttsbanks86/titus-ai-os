## Sequence Settings

### Timing
- **Send Time:** 9:00 AM (recipient's timezone)
- **Send Days:** Daily during launch week
- **Frequency:** 1 email per day

### Segmentation
- **Day 1:** Full list
- **Day 2-3:** Purchasers + non-purchasers
- **Day 4-5:** Purchasers (review request)
- **Day 6-7:** Non-purchasers (urgency)

### Tracking
- **Open Rate Goal:** 35%+
- **Click Rate Goal:** 10%+
- **Conversion Rate Goal:** 5%+

### Automation Rules
1. If purchased → Remove from urgency emails, send review request
2. If opened but not purchased → Resend with different subject
3. If reviewed → Send thank you + VIP access
4. If shared on social → Send bonus content
