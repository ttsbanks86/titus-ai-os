# 30-Day Tool Learning Plan

## Week 1: Excel
- Learn filtering, sorting, formulas, pivots
- Build a small KPI table

## Week 2: Jira
- Learn issues, boards, statuses, comments
- Create a sample backlog

## Week 3: Confluence
- Learn page structure, docs, meeting notes
- Write one clean requirements page

## Week 4: Power BI + SQL Basics
- Build a simple dashboard
- Learn SELECT, WHERE, JOIN, GROUP BY

## Daily Rule
- 30 minutes learning
- 30 minutes building
- 10 minutes writing what you learned

## Interview Rule
Be able to explain:
- what you used
- why you used it
- what problem it solved
