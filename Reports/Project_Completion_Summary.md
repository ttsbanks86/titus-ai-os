## Quick Start Guide

### 1. Enable MCPs
```bash
# Edit opencode.json to enable:
# - GitHub MCP (add PAT)
# - Notion MCP (token already available)
# - Tavily MCP (add API key)
```

### 2. Run Your First Command
```
# In OpenCode or Goose, say:
"Inbox triage my emails"
"Generate weekly pipeline report"
"Find leads for plumbers in Seattle"
```

### 3. Use the LeadGen System
```
# Start lead generation:
"Open LeadGen and find 20 leads for home service businesses"
"Analyze lead score for [company]"
"Create outreach sequence for [lead]"
```

### 4. Access Knowledge Base
```
# Get help:
"What's the SOP for email management?"
"Show me the email templates"
"What's the daily workflow?"
```
