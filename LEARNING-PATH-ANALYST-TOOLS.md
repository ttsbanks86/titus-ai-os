# Analyst Tool Learning Path

## Goal
Learn enough to speak confidently in interviews and show proof in your portfolio.

## Priority Tools
1. Excel
2. Jira
3. Confluence
4. Power BI
5. SQL basics

## What To Learn For Each

### Excel
- sorting and filtering
- pivot tables
- XLOOKUP / VLOOKUP
- IF / COUNTIF / SUMIF
- charts

### Jira
- issues
- boards
- statuses
- labels
- comments
- workflow basics

### Confluence
- pages
- meeting notes
- requirements docs
- process docs
- knowledge base structure

### Power BI
- import data
- simple visuals
- KPI cards
- filters
- basic dashboard layout

### SQL Basics
- SELECT
- WHERE
- JOIN
- GROUP BY
- ORDER BY

## Practice Rule
Do not try to master everything at once.
Learn one tool, build one artifact, then add it to the portfolio.

## Interview Proof
For each tool, be able to answer:
- What did I use it for?
- What problem did it help solve?
- What did I build with it?
